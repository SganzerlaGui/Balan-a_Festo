# ⚖️ Balança Industrial & Automação | Projeto Festo Brasil

> Sistema de automação industrial e pesagem desenvolvido na FIAP Challenge em parceria com a Festo Brasil, utilizando microcontrolador (ESP32) e célula de carga com amplificador HX711.

---

## 📌 Sobre o Projeto

Este repositório contém a aplicação de firmware responsável pela leitura, processamento e envio de dados de massa e automação para esteiras/linhas de produção em tempo real.

### 🛠️ Funcionalidades Principais:
- [x] Leitura contínua e calibração de dados de pesagem.
- [x] Integração para acionamento e controle de processos industriais.
      
---

## 🧰 Hardware e Componentes Utilizados

- **Microcontrolador:** ESP32 / Arduino
- **Sensor de Pesagem:** Célula de carga + Módulo Amplificador HX711

---

## 💻 Tecnologias e Linguagens

- **Linguagem / Firmware:** C++ / C (Arduino Framework)
- **IDE Utilizada:** Arduino-
-  **Bibliotecas Principais:** 
  - `HX711.h` (HX711 Arduino Library por Bogdan Necula) — *Leitura e calibração da célula de carga*
- **Versionamento:** Git / GitHub

---

## 🚀 Como Executar o Projeto

### Pré-requisitos
- **Arduino IDE** instalada na máquina.
- Placa ESP32/Arduino configurada na IDE.
- Biblioteca do **HX711** instalada no Gerenciador de Bibliotecas.
